# 지도·주변 탐색·모니터링 통합 QA

## 범위와 결과

- 로컬 production build의 mock 모드에서 실제 브라우저 상호작용을 실행했습니다.
- 최종 단위/상태 전이 테스트: 21개 파일, 143개 테스트 통과.
- 최종 브라우저 검사: 51개 고유 검사 모두 통과. 반복 시도의 마지막 결과를 검사명으로 집계했습니다.
- lint, typecheck, production build, `git diff --check` 통과.
- UI/재생/저장과 주변 탐색/API로 나눈 두 독립 최종 리뷰 모두 승인. 차단 보안/논리 오류 0건. 이전 동일 CCTV 오탐 상세 오류는 수정·상태 전이 테스트·브라우저 fixture 검사 후 재승인되었습니다.
- 독립 리뷰의 추가 권장 사항은 직접 onSnapshot/onClear 컴포넌트 회귀와 mounted StrictMode 회귀의 저장소 내 확장입니다. 현재 브라우저 지연 응답 검사와 순수 세션 취소 테스트는 통과했습니다.
- 비밀값 검사는 실제 키를 출력하지 않고 실행했으며, 소스·생성된 클라이언트 파일·mock API JSON·실제 모드 초기 HTML에서 일치 0건, `.env.local` ignored/untracked를 확인했습니다.

증빙: [검사 결과 JSON](qa/monitoring/checks.json), [모니터 화면](qa/monitoring/monitor-desktop.png), [320px 화면](qa/monitoring/dashboard-mobile-320.png).

## 확인한 동작

- 실제 Leaflet 지도, OSM 출처, 44px 마커, 긴급 후보의 실제 계산된 색상, 지도 높이.
- 마커 중심 좌표 클릭과 키보드 Enter의 CCTV 선택 연동.
- 지연된 갱신 응답 중 다른 CCTV를 선택해도 최신 선택과 빈 후보 상세 유지.
- TV 4대 추가, 중복/최대 대수 제한, 저장 필드 허용 목록, 재방문 복원.
- 순서 변경·제거 후 새로고침 복원, 명시적 영상 정보 갱신, 영상 자동 연결 없음.
- 제거된 TV의 늦은 메타데이터 응답 무시, 손상된 JSON 안전 처리, 저장 용량 오류 안내.
- 후보 없는 CCTV의 목록/지도 제외, 오탐 처리 후 지점 제거, 이력 재방문 반영, 마지막 후보 제거 후 다른 영상 대체 없음.
- 동일 CCTV에 A/B 후보가 있는 fixture에서 A를 오탐 처리하면 후보 전용 화면의 A 상세는 사라지고 CCTV와 B는 유지됨. 전체 화면의 과거 오탐 상세 열람은 유지됨.
- 위치 동의 전 GPS/API 요청 없음, 명시적 위치 요청, 거부 안내, 취소 이후 늦은 GPS/네트워크 응답 무시.
- 주변 결과의 직선거리 정렬·최단 CCTV 선택, 지역 유지 갱신과 최신 선택 보존, 위치 사용 중지.
- 요청에는 네 coarse bbox 필드만 포함하고 fixture의 정밀 좌표는 저장소에 남지 않음.
- 320/390/1440px 화면 넘침 없음.
- ITS 실제 모드의 초기 전체/후보 화면에 샘플 지점·샘플 감지·video·자동 API 요청 없음.

## 격리와 한계

- OSM 타일은 자동 QA에서 차단했습니다. 타일 오류 안내/목록 대체와 지도 마커·레이아웃을 검사했으며, 공용 타일을 반복 수집하지 않았습니다.
- 위치 권한과 GPS는 테스트 fixture입니다. 사용자의 실제 위치를 요청하거나 저장하지 않았습니다. 주변 결과는 mock API 응답을 실제로 받아 검사했습니다.
- 같은 CCTV의 복수 후보 검사는 mock 응답의 두 번째 후보를 같은 CCTV에 배정한 테스트 fixture이며 실제 감지 결과가 아닙니다.
- 실제 모드는 초기 렌더와 키 비노출만 검사했으며, 이 QA에서 실제 ITS metadata/영상 조회를 추가 실행하지 않았습니다. 앞선 실제 재생 35초 검증은 [재생 진단](playback-diagnosis.md)에 별도 기록했습니다.
- 자동 영상 분석기는 미연결입니다. 실서비스 공개, 영상 저장/재배포/분석 권한, 분산 rate limit, 공급자 호출 한도 확정은 별도 배포 전 과제입니다.

## 이번에 수정한 회귀

- localStorage 검토 이력을 초기 렌더에서 직접 읽던 경로를 SSR-safe external store로 변경했습니다.
- 후보 전용 화면의 선택 상세에도 오탐 제외 범위를 적용했습니다.
- `@tailwindcss/turbopack`의 전체 CSS 규칙이 CSS Modules export를 없애 지도 높이가 0이 되던 문제를 `globals.css` 한정 규칙으로 수정했습니다. 빌드 성공뿐 아니라 실제 브라우저 높이·색상·크기를 재검증했습니다.

Next 스트리밍 HTML의 입력 존재만으로 hydration 완료로 판단한 초기 자동화 실패는 제외하지 않고 원인 조사 후, client effect로 생성된 마커/실제 소스 상태가 준비된 뒤 같은 검사를 다시 실행했습니다. 위 JSON은 안정된 준비 조건에서 얻은 각 검사의 최종 결과입니다.
