# API 발급 준비

## 지금 필요한 항목: ITS CCTV 화상자료 인증키

현재 앱에는 ITS CCTV adapter가 있으므로 먼저 이 서비스만 신청합니다. 공식 CCTV 화상자료 페이지는 고속도로·국도 영상을 제공하며, 필수 요청변수로 발급받은 `apiKey`를 요구합니다. 해당 페이지의 `인증키 신청` 버튼을 사용합니다.[1]

- 사이트: https://www.its.go.kr/
- 경로: 회원가입/로그인 → 오픈데이터 → CCTV 화상자료 → 인증키 신청
- 서비스: **CCTV 화상자료** (페이지의 서비스 식별자 `OPD_00000003`)
- 현재 연동 목표: 고속도로 `type=ex`, HTTPS HLS `cctvType=4`, JSON 응답. 공식 페이지에 해당 유형과 형식이 안내되어 있습니다.[1]
- 발급 신청만 진행하고 실제 호출은 이용조건 확인 후 별도로 진행합니다.

### 활용목적 작성 예시

> 고속도로 CCTV 위치와 영상을 확인하고 운영자가 교통상황 후보를 검토하는 웹 기반 개인 개발 프로젝트입니다. 우선 소수 지점의 연결·재생을 검증하려고 합니다. 영상 저장·재배포는 하지 않으며, 프레임 추출 및 AI 분석은 허용 범위를 확인한 뒤 적용할 예정입니다.

이는 신청서 작성 초안입니다. 실제 공개 범위와 이용 목적에 맞게 수정합니다. 공개 웹 서비스, 상업적 이용, 프레임 추출·분석, 저장·재배포는 인증키 발급만으로 허용된 것으로 간주하지 않습니다. ITS의 일반 저작권 정책은 복제·배포 제한 및 수익 목적 이용에 대한 사전 협의를 안내하므로 CCTV/API의 구체적인 허용 범위를 제공기관에 확인합니다.[2]

### 발급 시 함께 확인할 사항

- 개인 개발·내부 검증과 공개 웹 서비스 각각의 허용 범위
- 라이브 영상의 브라우저 재생, 출처 표기 방식
- 프레임 추출/AI 분석 허용 여부와 분석 결과 표시 조건
- 트래픽 한도, 스트림 URL 수명, 재조회 권장 간격, 등록 IP/도메인 등 신청 조건
- 썸네일·영상 저장 및 재배포 가능 여부 (현재 앱은 저장/재배포를 하지 않음)

공식 CCTV 페이지의 `4001` 사용량 제한, `4005` 인증키 오류 등도 확인합니다. 실제 한도나 승인 소요시간은 신청 화면/제공기관 안내로 확인하며 여기서 임의로 단정하지 않습니다.[1]

### 키 보관

실제 인증키를 채팅·문서·코드·Git 커밋에 넣지 않습니다. 로컬 `.env.local`의 `ITS_API_KEY`에만 보관하며 `NEXT_PUBLIC_` 변수로 만들지 않습니다. 현재는 `CCTV_SOURCE_MODE=mock`을 유지합니다. 발급 후에는 키 대신 **발급 완료 여부와 이용조건**을 공유하면 됩니다. 실제 호출 전 절차는 [ITS 연동 안내](its-integration.md)를 참고합니다.

## 지금 발급하지 않아도 되는 항목

- 지도 API: 현재는 자체 SVG/좌표 기반 개략도이므로 지도 키가 필요 없습니다. 실제 도로 타일·확대/축소·다수 지점 클러스터링이 필요해질 때 제공자를 정합니다.
- AI/VLM API: 현재 후보 데이터는 샘플이며 외부 AI 모델 호출을 구현하지 않았습니다. API 결제·키 발급이 필요하지 않습니다.
- 기상·소통·공사/사고 API: 현재 단계의 필수 의존성이 아닙니다. 후속 교차검증 기능의 범위를 정한 뒤 신청합니다.
- 공공데이터포털 키: 현재 adapter는 ITS 직접 인증키 방식입니다. 별도 키를 중복 발급받을 필요는 없습니다.
