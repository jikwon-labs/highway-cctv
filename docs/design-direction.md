# 디자인 방향

## 문제

기존 화면은 어두운 배경, 네온 계열 강조색, 큰 둥근 카드, 과한 "AI" 표현 때문에 실제 관제 도구보다 데모용 AI 제품처럼 보였다. 문구도 사용자가 할 일을 바로 알려주기보다 홍보 문장처럼 읽혔다.

## 변경 방향

- 어두운 네온 대시보드에서 밝은 운영 도구 화면으로 전환
- 큰 둥근 카드, 글로우, 그라디언트 제거
- IBM Carbon에 가까운 중립 팔레트 사용: 흰색, 회색, 검정, 파란색 하나
- 텍스트는 기능 중심으로 축소
- "AI 이벤트" 대신 "감지 후보" 사용
- "확정"보다 "검토"를 전면에 둠
- 영상 저장, 자동 판정 같은 오해를 줄이는 문구 유지

## 새 톤

- 제품 홍보보다 관제 업무 화면
- 감성적 문구보다 상태, 후보, 검토 중심
- AI가 주인공이 아니라 운영자가 주인공

## UI 원칙

- 표면은 평평하게, 구분은 선과 배경색으로 처리
- 상태 색상은 의미가 있을 때만 사용
- CTA는 하나만 강하게 표시: 데이터 갱신
- 이벤트 카드는 심각도 색상 막대만 사용
- 문장은 짧게 쓴다
- CCTV 선택은 목록만 쓰지 않고 지도 지점 클릭으로도 가능하게 한다
- 실제 연결 전 소스 권한, 저장 제한, 재배포 제한을 UI에서 항상 보이게 한다
- 이벤트 검토는 일회성 버튼이 아니라 최근 처리 이력으로 남겨 운영 흐름을 보여준다
- 확인/오탐 처리에는 짧은 처리 사유를 남겨 나중에 오탐 패턴과 운영 판단을 되짚을 수 있게 한다
